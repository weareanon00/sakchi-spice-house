# 🍽️ Sakchi Spice House

A modern, responsive restaurant website designed for a local Indian restaurant.

## 🌐 Live Demo

[View Live Website](https://weareanon00.github.io/sakchi-spice-house/)

## 📌 About The Project

Sakchi Spice House is a responsive restaurant website created to provide customers with an easy way to explore the restaurant, browse the menu, view food items, read reviews, and contact the restaurant.

The project focuses on a clean modern design, responsive layout, smooth navigation, and an easy-to-use menu interface.

## ✨ Features

- Responsive design for mobile, tablet and desktop
- Modern restaurant landing page
- Interactive navigation
- Food menu with categories
- Search menu items
- Food item cards
- Special offers section
- Shopping cart interface
- About restaurant section
- Gallery section
- Customer reviews
- Contact section
- WhatsApp ordering integration
- Smooth scrolling
- Mobile-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile phones

This project was created as a portfolio project and as a demonstration of frontend web development skills for small businesses and restaurants.
